# Technology Stack — Portfolio OS

This document describes the dependencies and structure in the current repository. The package manifest and lockfile are the source of truth for installed versions.

## Core application

- **Next.js 16.2.1 App Router** for routing, page metadata, metadata endpoints, and production rendering.
- **React 19.2.4** for UI components and client-side interactions.
- **TypeScript** with the repository's strict compiler settings.
- **Tailwind CSS v4** for the dark visual system and responsive layouts.

## Interaction and motion

- **Framer Motion** for project-card transitions, the detail window, and interface transitions.
- **GSAP + ScrollTrigger** for narrative timeline effects.
- **Lenis** for smooth scrolling when the user has not requested reduced motion.
- **Lucide React** for interface icons.
- **Inter** and **JetBrains Mono** loaded through Next.js font tooling.

Animation lifecycles are scoped and cleaned up. Reduced-motion preference disables the Lenis loop and GSAP timeline animations, with CSS fallback rules for animated elements.

## Registry and validation

- lib/data/projects.ts is the single source of truth for project cards and detail windows.
- Each project records a category, publication/status label, stack when known, concise narrative fields, and optional verified links.
- scripts/validate-projects.mjs uses Node's built-in assertions to check registry uniqueness, required fields, HTTPS URLs, repository URL shape, and exclusion of known private source links.
- GitHub Actions runs lint, TypeScript, registry checks, and the production build for pull requests and pushes to main.

## Source layout

~~~text
app/
  layout.tsx                 Root layout, metadata and viewport settings
  page.tsx                   Timeline, registry and contact links
  globals.css                Theme, focus styles and reduced-motion CSS
  manifest.ts                Web application manifest
  robots.ts                  Crawler rules
  sitemap.ts                 Canonical home-page sitemap
  opengraph-image.tsx        Social-sharing image generated by Next.js
components/os/
  Dashboard.tsx              Registry search, category filters and modal state
  ProjectModule.tsx          Project card and explicit link actions
  ProjectWindow.tsx          Accessible project-detail dialog
  SystemActivityLog.tsx      Non-telemetry decorative activity trace
  SystemLoader.tsx           Optional intro animation
  SystemStatusBar.tsx        Portfolio label and local clock
lib/animations/
  ScrollEngine.tsx           Lenis and ScrollTrigger lifecycle
lib/data/
  projects.ts                Typed project registry
scripts/
  validate-projects.mjs      Registry checks
~~~

The main application does not currently use a CMS, analytics API, production telemetry feed, or live GitHub statistics endpoint. Interface decorations must not be presented as measured health, throughput, or integrity data.

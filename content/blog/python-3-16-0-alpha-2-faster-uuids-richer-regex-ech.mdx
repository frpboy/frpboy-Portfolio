The second alpha of Python 3.16 landed on 10 November. It's an early developer preview - features can change until beta 1 in May 2027 and the final release is planned for October 2027 - but it's a good time to run your test suite against it.

What's landing so far, compared with 3.15:

**More expressive regular expressions.** The `re` module now supports nested character sets, set operations such as intersection and difference, and matching characters by Unicode properties (for example, uppercase letters).

**Faster startup.** Python starts faster, and several common operations were optimised, including garbage collection and the construction of built-in objects.

**Faster UUID generation.** `uuid4()` and `uuid7()` now have C implementations, making generation about 15-30x faster than the pure Python implementations in microbenchmarks.

**Encrypted Client Hello.** The `ssl` module adds support for ECH when built with OpenSSL 4.0 or later.

**More Apple platforms.** CPython can now be built for tvOS, watchOS and visionOS (not yet in the PEP 11 supported tiers).

The next alpha, 3.16.0a3, is scheduled for 15 December. If you maintain a library, alpha season is the cheapest time to catch breakage - a CI job against the preview costs little and surfaces deprecations months before users hit them.
